# NSL-KDD Dataset

This directory is where the NSL-KDD dataset files used in the intrusion detection experiments should be placed. The files are downloaded from Kaggle and are included here, unmodified, so that the experiments can be reproduced. All credit for the dataset belongs to its original authors (see below).

## Files

- `KDDTrain+.txt` — training dataset
- `KDDTest+.txt` — official test dataset

## Source

Kaggle: [NSL-KDD Dataset](https://www.kaggle.com/datasets/hassan06/nslkdd)

## Original Dataset Publication

M. Tavallaee, E. Bagheri, W. Lu, and A. A. Ghorbani, "A detailed analysis of the KDD CUP 99 data set," in *Proceedings of the 2009 IEEE Symposium on Computational Intelligence for Security and Defense Applications (CISDA)*, 2009, pp. 1–6.

## Usage

The notebooks expect the dataset files to be located in this directory:

```text
datasets/nsl-kdd/KDDTrain+.txt
datasets/nsl-kdd/KDDTest+.txt
```
